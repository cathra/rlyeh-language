# Rlyeh 快照基线清单（SH-P2-5 C2，0.2.0 PoC）
#
# 每行一个 .rl 相对路径（相对仓库根）；`#` 开头为注释。
# 用法:
#   python3 scripts/diff_harness.py update --manifest tests/snapshot-baseline.txt --dims run
#   python3 scripts/diff_harness.py check --manifest tests/snapshot-baseline.txt --dims run
#
# 选取原则: 运行行为（run 输出）确定、无并发/无哈希序依赖/无 IO 副作用
# 的用例，作为编译器语义回归的轻量基线。AST/HIR/IR 因被 std 前缀主导
# （单程序 AST ~21 万行），不逐程序存储，留作未来双编译器 `--rlyeh-b` 差分。
