# 每行一个 .rl 相对路径（相对仓库根）；`#` 开头为注释。
# 用法:
#   python3 scripts/diff_harness.py update --manifest tests/snapshot-baseline-hir-probe.txt --dims hir-user
#   python3 scripts/diff_harness.py check --manifest tests/snapshot-baseline-hir-probe.txt --dims hir-user
#
# 维度说明: `hir-user` 经 driver `emit_hir_user` 完整类型检查后，按 `HirItem.span`
# 字节偏移过滤掉落在 `prelude_len`（std 预置）之前的项，仅保留用户源码项。
# 单程序仅数十~千余行（full `hir` 达 ~3.5 万行），适合作为 HIR 快照基线，

# 故泛型/闭包程序的 hir-user 仅含其非泛型用户项。
#
# 选取原则: 多样性（控制流/枚举/布局/转换/元组/字符串/泛型/函数指针等）、
# 确定性高、无并发/无 IO 副作用。新增用例须确认 `hir-user` 产物稳定且体积可控。
