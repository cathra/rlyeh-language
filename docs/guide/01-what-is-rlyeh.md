# 1. 认识 Rlyeh

> 本章目标：用最短篇幅让你建立对 Rlyeh 的整体印象——它是什么、为什么存在、和 C 有什么关系。更系统的"为什么"与"对比"见 [教程 · 认识 Rlyeh](../tutorial/01-what-is-rlyeh.md)（面向零基础读者的详细版）。
>
> 本指南的定位是**语言教程**：每个知识点都有可运行示例，建议按顺序读。

---

## 1.1 一句话定位

**Rlyeh 是一门系统级编程语言**，编译为原生机器码，能用在所有需要"接近硬件 + 高性能"的地方（操作系统、数据库、网络服务、嵌入式）。它的设计公式是：

> **Rlyeh = Rust 的安全性 + Go 的编译速度 + Erlang 的并发模型 + 数学的自然表达。**

| 设计目标 | 对标 | 落地形态 |
|----------|------|----------|
| 内存安全、零 GC | Rust | 分层内存模型（L0 所有权 → L1 区域 → L2 Rc → L3 GC） |
| 编译速度极快 | Go | 模块级缓存（增量编译，已实现）、函数级并行（规划中） |
| 并发模型一等公民 | Erlang / Akka | `actor` 语言级构造 + 运行时监督 |
| 数学式语法直觉 | Python / MATLAB | 比较链 `0 < x < 10`、集合判断 `x in (1, 3, 5)` |

> **对 C 程序员的补充**：Rlyeh 不是自动垃圾回收语言（不像 Java/Python/Go 后台跑 GC）。**默认零运行时开销**，GC 只在你主动选择时才出现。它的内存安全来自编译期分析，而非运行时负担——这点让它和 C 一样快，又比 C 安全。

---

## 1.2 和 C 的"同"与"异"

**相同的（可直接复用直觉）**：值语义、`for`/`if`/`while`、函数指针、栈上局部变量、指针（`*const T`/`*mut T`）、`match` 取代 `switch`、`extern "C"` 调用 C 函数。

**不同的（需要重新建立心智模型）**：

| C 的习惯 | Rlyeh 的做法 | 带来的好处 |
|----------|--------------|------------|
| `const int x` 是可选的 | 变量**默认不可变**（`let`），要改写 `let mut` | 减少意外修改 |
| 手动 `malloc`/`free` | 编译期追踪所有权/借用，或区域批量释放 | 杜绝悬垂/泄漏/双重释放 |
| 共享内存 + 锁 | Actor 消息传递（不共享内存） | 消灭数据竞争 |
| `a < x && x < 10` | `a < x < 10`（比较链） | 更直观、不易笔误 |
| `NULL` / `-1` 表示失败 | `Option` / `Result` 类型强制处理 | 编译期逼你处理错误 |
| `#include` 全量灌入 | `import` 按需取符号 | 更精准、无全局污染 |

## 1.3 当前进度（MVP 0.1.0）

建议顺序：`01 认识` → `02 快速上手` → `03 基础语法` → …… 每章独立成文，遇到不懂的概念可随时跳到相关章节。需要速查时转 [语言手册](../manual/index.md)；需要权威语法/语义定义转根目录 `grammar.md` / `semantics.md` 等。

## 练习

1. 安装工具链后，运行 [`examples/by-chapter/01-what-is-rlyeh.rl`](../../examples/by-chapter/01-what-is-rlyeh.rl)，确认输出 `Hello, Rlyeh!`。
2. 把 `let x = 6;` 改成 `let mut x = 6; x = x + 1;`，观察 Rlyeh "默认不可变"与 C 的 `int x = 6;` 随时可改的差异。
3. 思考：C 里你靠什么手段保证"变量不被意外修改"？Rlyeh 把 `let`/`let mut` 变成**默认不可变**，这带来什么好处、又牺牲了什么便利？
