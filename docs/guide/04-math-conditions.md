# 4. 数学式条件判断

Rlyeh 最直观的语法特性：比较链与集合判断，让条件表达式贴近数学直觉。

## 4.1 区间内（正向比较链）

```rlyeh
if 0 < x < 10 {}      // 0 < x && x < 10
if 0 <= x <= 10 {}    // 0 <= x && x <= 10
if 0 < x <= 10 {}     // 0 < x && x <= 10
```

## 4.2 区间外（反向比较链）

```rlyeh
if 0 > x > 10 {}      // x < 0 || x > 10（反向外链 = 并集）
if 0 >= x >= 10 {}    // x <= 0 || x >= 10
```

## 4.3 集合判断（括号内为离散集合）

```rlyeh
if x in (1, 3, 5) {}                          // x == 1 || x == 3 || x == 5
if ch in ('a'..<'z', 'A'..<'Z') {}            // 范围元素展开为离散成员
if x in (0...10) {}                           // 等价 x == 0 || ... || x == 10
if x not in (0..<10) {}                       // 不等价于全部（!x in）
```

## 4.4 裸范围 = 区间判断

```rlyeh
if x in 0..<10 {}    // 0 <= x < 10     [0, 10)
if x in 0...10 {}    // 0 <= x <= 10    [0, 10]
if x in 0<..10 {}    // 0 < x <= 10     (0, 10]
```

## 4.5 时间字面量

```rlyeh
if hour in (9am...6pm) {}             // 工作时间段
if hour not in (6am..<10pm) {}        // 跨午夜自动处理
```

时间字面量（`9am` = 540、`6pm` = 1080，单位分钟）可参与比较链与 `in` 区间判断，常用于调度 / 窗口场景。
