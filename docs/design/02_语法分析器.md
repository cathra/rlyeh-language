## 目标

将 Token 流解析为 AST（抽象语法树），支持所有 Rlyeh 语法特性。

## AST 节点类型

### 表达式 (Expr)
```
Expr:
  | Literal(Literal)
  | Ident(String)
  | Binary(Box<Expr>, BinOp, Box<Expr>)
  | Unary(UnaryOp, Box<Expr>)
  | Call(Box<Expr>, Vec<Expr>)
  | MethodCall(Box<Expr>, String, Vec<Expr>)
  | If(Box<Expr>, Box<Block>, Option<Box<Expr>>)
  | Match(Box<Expr>, Vec<MatchArm>)
  | Block(Vec<Stmt>)
  | Region(String, Option<RegionOptions>, Box<Block>)
  | Transfer(Box<Expr>, String)  // transfer x out of 'r
  | In(Box<Expr>, Vec<InPattern>)  // x in (1, 2, 3)
  | ComparisonChain(Vec<Expr>, Vec<CompOp>)  // 0 < i < 10
  | Async(Box<Block>)
  | Await(Box<Expr>)
  | Assign(Box<Expr>, Box<Expr>)
  | Index(Box<Expr>, Box<Expr>)
  | Tuple(Vec<Expr>)
  | Array(Vec<Expr>)
  | Range(Option<Box<Expr>>, Option<Box<Expr>>, RangeKind)
```

### 语句 (Stmt)
```
Stmt:
  | Let { name, type_ann, init, mutable }
  | Fn { name, params, return_type, body, generics, where_clause }
  | Struct { name, fields, generics }
  | Enum { name, variants, generics }
  | Impl { target, protocol_, methods }
  | Protocol { name, methods }
  | Actor { name, fields, methods }
  | Mod { name, items }
  | Use { path, alias }
  | Expr(Expr)
  | Return(Option<Expr>)
  | Break(Option<Expr>)
  | Continue
```

### 模式 (Pattern)
```
Pattern:
  | Wildcard
  | Ident(String)
  | Literal(Literal)
  | Tuple(Vec<Pattern>)
  | Struct(String, Vec<(String, Pattern)>)
  | Range(Expr, Expr, RangeKind)
  | Guard(Box<Pattern>, Box<Expr>)
```

## 语法规则（EBNF 简化）

### 比较链（核心特性）
```
comparison_chain ::= expression (comp_op expression)*
comp_op ::= '<' | '<=' | '>' | '>=' | '==' | '!='

// 语义规则：
// - 所有运算符方向一致 → 区间内（正向）
// - 所有运算符方向反转 → 区间外（反向）
// - 方向不一致 → 编译错误
```

### in 表达式
```
in_expr ::= expression 'in' '(' pattern_list ')'
pattern_list ::= range | value (',' value)*
range ::= expression '..' expression
        | expression '..=' expression
        | '(' expression ',' expression ')'
        | '[' expression ',' expression ']'
        | '(' expression ',' expression ']'
        | '(' expression ',' expression ')'
```

### region 块
```
region_stmt ::= 'region' region_name region_options? block
region_name ::= ''' identifier
region_options ::= 'with_size' '(' expression ')'
                 | 'allow_growth' '(' 'growth_factor' '=' number ')'
                 | 'strategy' '(' ('auto'|'static'|'pgo'|'adaptive') ')'
                 | 'hint' '(' ('size' '=' expression | 'max' '=' expression) ')'
                 | 'exact' '(' 'size' '=' expression ')'
```

### transfer 语句
```
transfer_expr ::= 'transfer' expression 'out' 'of' region_name
```

### 函数定义
```
fn_def ::= 'fn' ident '(' params ')' ('->' type)? where_clause? block
params ::= param (',' param)*
param ::= ident ':' type | ident ':' type '=' literal
```

### actor 定义
```
actor_def ::= 'actor' ident '{' actor_body '}'
actor_body ::= (actor_field | actor_method)*
actor_method ::= 'pub'? 'async'? fn_def
```

## 解析策略

- 使用**递归下降 + Pratt 解析器**处理运算符优先级
- 比较链作为特殊的表达式节点，在解析阶段识别
- `in` 关键字需要向后看 2 个 Token 以区分 `in` 表达式和 `for ... in` 循环

## 交付物

- `parser.rs`：语法分析器
- `ast.rs`：AST 节点定义
- `precedence.rs`：运算符优先级表
- `parser_test.rs`：解析测试
- `fixtures/`：测试用的 Rlyeh 源文件

## 验收标准

1. 能正确解析所有 Rlyeh 语法
2. 比较链 `0 < i < 10` 生成正确的 AST
3. `in` 表达式正确区分集合和区间
4. region/transfer 语法正确解析
5. 错误信息包含精确的行号和列号
6. 性能：百万行代码解析时间 < 2s
