## 任务描述

实现编译器流水线中的 **Borrow Checker**（Type Checker → **Borrow Checker** → Region Checker）——L0 静态所有权系统的核心，补齐里程碑 **M1.5**。

MVP 阶段检查范围（不依赖类型标注、不误报合法代码）：

| 检查 | 语义 | 对应 Rust |
|------|------|-----------|
| **use-after-move** | 变量被 `transfer` 转移所有权后再次使用 | E0382 |
| **不可变绑定赋值** | 对非 `let mut` 绑定赋值（含 `+=` 等复合赋值） | E0384 |
| **transfer 重复** | 对已转移变量再次 `transfer`（borrowck 视角） | E0382 |
| **区域块值传递例外** | `transfer x out of 'r; x` 中 `x` 作区域块尾值 = 所有权转出，合法 | — |

## 设计

### 为什么只查这两类？

- **借用互斥规则**（`&`/`&mut`）依赖引用语法，MVP 阶段 typecheck 对 `&` 返回 `Unsupported`；
- **一般 move**（`let y = x;` 后 `x` 不可用）依赖 Copy/非 Copy 类型区分，而 HIR 无类型标注；
- **transfer 是语言中唯一明确的所有权转移路径**（ADR-003），可无歧义静态跟踪。

### 核心结构

```rust
// crates/rlyeh-borrowck/src/checker.rs
struct Binding { mutable: bool, transferred: bool }  // 单绑定所有权信息
struct Scope  { bindings: HashMap<String, Binding> } // 词法作用域
struct BorrowChecker { scopes: Vec<Scope>, errors: Vec<BorrowError> }
```

### 遍历规则

- 每个函数独立作用域，参数注册为不可变绑定；
- `HirStmt::Let`：**先检查 init 再注册绑定**（shadowing 时 init 引用旧绑定）；
- `HirExpr::Variable(x)`：`x.transferred` → `UseAfterTransfer`；
- `HirExpr::Assign { target }`：`transferred` → `UseAfterTransfer`（优先）；否则不可变 → `AssignToImmutable`；
- `HirExpr::Transfer { expr }`：变量形式 → 标记 `transferred = true`（簿记，不读取值）；非变量形式 → 递归（regionck 报 PartialTransfer）；
- `Region` / `Block` / `If` / `While` / `Loop`：push/pop 作用域；
- **transfer 传递例外**：仅区域块（`HirExpr::Region`）的尾值允许"已转移变量直接以变量形式传递"，其余位置读取一律报错（`{ x }` 块包裹等保守拒绝）。

### 错误类型

```rust
pub enum BorrowError {
    UseAfterTransfer { name, line, col },  // use of moved value
    AssignToImmutable { name, line, col }, // cannot assign to immutable variable
    BorrowConflict { detail, line, col },  // 防御性：&/&mut 互斥（待引用语法）
    MoveWhileBorrowed { detail, line, col }, // 防御性：借用中 move（待引用语法）
}
```

## 落地偏差说明

- **错误位置占位**：HIR 节点不携带源码位置（rlyeh-hir 约定），`line`/`col` 恒为 0，待 Span 传播后填充（与 regionck 一致）。
- **保守拒绝**：已转移变量仅允许作为区域块尾值的直接变量形式传递；`{ x }`、`if` 分支等复合路径一律报错，待语义明确后放宽。
- **重复报告**：`transfer x; transfer x;` 在 regionck 侧报 `DoubleTransfer`，borrowck 侧报 `UseAfterTransfer`，两检查器独立，不互相依赖。
- **一般 move 未覆盖**：无类型标注无法区分 Copy/非 Copy，`let y = x; use(x)` 暂不检查（留待 HIR 携带类型后启用）。
- **未接线 driver**：borrowck 尚未接入 `rlyeh-driver` 流水线（M1.8 代码生成时统一接线）。
