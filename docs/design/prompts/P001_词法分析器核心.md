# P001: 词法分析器核心 (rlyeh-lexer)

> **模块路径**：`crates/rlyeh-lexer/`  
> **预估工期**：3-5 天  
> **前置依赖**：无（第一个任务）  
> **输出**：可工作的词法分析器，能将 Rlyeh 源代码转换为 Token 流

---

## 任务描述

实现一个完整的 Rlyeh 语言词法分析器（Lexer / Tokenizer），支持所有关键字、运算符、字面量和特殊语法元素。

---

## 必须支持的语言元素

### 关键字

```
let, mut, const, static, fn, return, pub, priv
if, else, match, for, while, loop, break, continue
true, false, and, or, not
struct, enum, trait, impl, type, where, Self
region, in, transfer, out, of, unsafe
actor, async, await, spawn, send, recv
mod, use, as, extern
@bind_from_c_header, @specialize, @for
```

### 运算符

```
+  -  *  /  %  ==  !=  <  <=  >  >=
&&  ||  !  &  |  ^  <<  >>
=  +=  -=  *=  /=  %=
..<  ...  <..
->  =>
```

### 特殊语法

```
in (a, b, c)         （集合成员判断，编译期展开为 == 链）
in (a..<b)           （集合内范围元素，离散展开为 == 链）
in a..<b / a...b     （in 右侧裸范围，区间判断，展开为 >= && <）
not in (a, b, c)      （集合补，编译期展开为 != 链）
9am, 6pm              （时间字面量）
22:00                 （时间字面量）
```

## 必须实现的功能清单

### 1. 基础词法分析

- [ ] 跳过空白（空格、tab、换行、回车）
- [ ] 跳过单行注释 `//`
- [ ] 跳过块注释 `/* */`（支持嵌套）
- [ ] 位置跟踪（行号、列号）

### 2. 标识符与关键字

- [ ] 标识符规则：`[a-zA-Z_][a-zA-Z0-9_]*`
- [ ] 原始标识符：`r#keyword`
- [ ] 全部关键字识别

### 3. 数字字面量

- [ ] 十进制：`42`, `1_000_000`
- [ ] 十六进制：`0xFF`, `0xDEAD_BEEF`
- [ ] 二进制：`0b1010`
- [ ] 八进制：`0o755`
- [ ] 浮点数：`3.14`, `2.5e-10`, `1.0f32`
- [ ] 类型后缀：`42i32`, `3.14f64`

### 4. 字符串与字符

- [ ] 字符串字面量 `"hello"`
- [ ] 转义序列：`\n`, `\t`, `\r`, `\\`, `\"`, `\'`, `\xHH`
- [ ] Unicode 转义：`\u{1F600}`
- [ ] 原始字符串：`r"hello\nworld"`（不处理转义）
- [ ] 字符字面量：`'a'`, `'\n'`, `'\u{1F600}'`

### 5. 时间字面量

- [ ] `9am` → `TimeLiteral { hour: 9, minute: 0, is_pm: false }`
- [ ] `6pm` → `TimeLiteral { hour: 18, minute: 0, is_pm: true }`
- [ ] `22:00` → `TimeLiteral { hour: 22, minute: 0, is_pm: false }`
- [ ] `09:30am` → `TimeLiteral { hour: 9, minute: 30, is_pm: false }`

### 6. 运算符

- [ ] 单字符：`+ - * / % = < > ! & | ^`
- [ ] 双字符：`== != <= >= && || << >> ..<`
- [ ] 三字符：`...`（闭区间）
- [ ] 范围：`..<`（左闭右开），`...`（闭区间），`<..`（左开右闭）
- [ ] 箭头：`->`（函数返回），`=>`（match 分支）

### 7. 特殊组合

- [ ] `not in` → 识别为 `NotIn` 复合 Token

## 测试用例

```rust
// crates/rlyeh-lexer/tests/lexer_test.rs

#[test]
fn test_basic_keywords() {
    let mut lexer = Lexer::new("let mut fn return if else");
    let tokens = lexer.tokenize().unwrap();
    assert_eq!(tokens[0].token, Token::Let);
    assert_eq!(tokens[1].token, Token::Mut);
    assert_eq!(tokens[2].token, Token::Fn);
    assert_eq!(tokens[3].token, Token::Return);
    assert_eq!(tokens[4].token, Token::If);
    assert_eq!(tokens[5].token, Token::Else);
}

#[test]
fn test_numbers() {
    let mut lexer = Lexer::new("42 3.14 0xFF 0b1010 1_000_000");
    let tokens = lexer.tokenize().unwrap();
    assert_eq!(tokens[0].token, Token::IntLiteral(42));
    assert_eq!(tokens[1].token, Token::FloatLiteral(3.14));
    assert_eq!(tokens[2].token, Token::IntLiteral(255));
    assert_eq!(tokens[3].token, Token::IntLiteral(10));
    assert_eq!(tokens[4].token, Token::IntLiteral(1000000));
}

#[test]
fn test_strings() {
    let mut lexer = Lexer::new(r#""hello\nworld" 'a' '\n'"#);
    let tokens = lexer.tokenize().unwrap();
    assert_eq!(tokens[0].token, Token::StringLiteral("hello\nworld".to_string()));
    assert_eq!(tokens[1].token, Token::CharLiteral('a'));
    assert_eq!(tokens[2].token, Token::CharLiteral('\n'));
}

#[test]
fn test_time_literals() {
    let mut lexer = Lexer::new("9am 6pm 22:00 09:30am");
    let tokens = lexer.tokenize().unwrap();
    
    if let Token::TimeLiteral { hour, minute, is_pm } = tokens[0].token {
        assert_eq!(hour, 9);
        assert_eq!(minute, 0);
        assert!(!is_pm);
    } else { panic!("expected TimeLiteral"); }
    
    if let Token::TimeLiteral { hour, minute, is_pm } = tokens[1].token {
        assert_eq!(hour, 18);
        assert!(is_pm);
    } else { panic!("expected TimeLiteral"); }
}

#[test]
fn test_comparison_operators() {
    let mut lexer = Lexer::new("0 < x < 10");
    let tokens = lexer.tokenize().unwrap();
    // 应该识别出：IntLiteral(0), Lt, Ident("x"), Lt, IntLiteral(10)
    assert_eq!(tokens[0].token, Token::IntLiteral(0));
    assert_eq!(tokens[1].token, Token::Lt);
    assert_eq!(tokens[2].token, Token::Ident("x".to_string()));
    assert_eq!(tokens[3].token, Token::Lt);
    assert_eq!(tokens[4].token, Token::IntLiteral(10));
}

#[test]
fn test_not_in_combo() {
    let mut lexer = Lexer::new("x not in (1, 2, 3)");
    let tokens = lexer.tokenize().unwrap();
    assert_eq!(tokens[1].token, Token::NotIn);
}

#[test]
fn test_region_keyword() {
    let mut lexer = Lexer::new("region 'r { let x = 42 in 'r; }");
    let tokens = lexer.tokenize().unwrap();
    assert_eq!(tokens[0].token, Token::Region);
    // ... 验证完整 token 序列
}

#[test]
fn test_unterminated_string() {
    let mut lexer = Lexer::new(r#""hello world"#);
    let err = lexer.tokenize().unwrap_err();
    assert!(matches!(err, LexError::UnterminatedString { .. }));
}

#[test]
fn test_invalid_escape() {
    let mut lexer = Lexer::new(r#""hello\qworld""#);
    let err = lexer.tokenize().unwrap_err();
    assert!(matches!(err, LexError::InvalidEscape { .. }));
}

#[test]
fn test_position_tracking() {
    let source = "let x = 42;";
    let mut lexer = Lexer::new(source);
    let tokens = lexer.tokenize().unwrap();
    
    // 'let' 从位置 0 开始
    assert_eq!(tokens[0].span.start, 0);
    assert_eq!(tokens[0].span.line, 1);
    assert_eq!(tokens[0].span.col, 1);
    
    // '42' 的位置
    assert_eq!(tokens[3].span.col, 9);
}

#[test]
fn test_nested_block_comments() {
    let source = "/* outer /* inner */ still comment */ let x = 1;";
    let mut lexer = Lexer::new(source);
    let tokens = lexer.tokenize().unwrap();
    assert_eq!(tokens[0].token, Token::Let);
}
```

```rust
// crates/rlyeh-lexer/benches/lexer_bench.rs
use criterion::{black_box, Criterion};

fn bench_small_file(c: &mut Criterion) {
    let source = "let x = 42; if x > 0 { println!(\"{}\", x); }";
    c.bench_function("lex_small", |b| {
        b.iter(|| {
            let mut lexer = Lexer::new(black_box(source));
            lexer.tokenize().unwrap()
        })
    });
}

fn bench_large_file(c: &mut Criterion) {
    // 模拟 10K 行代码
    let source = std::fs::read_to_string("large_input.rl").unwrap();
    c.bench_function("lex_10k_lines", |b| {
        b.iter(|| {
            let mut lexer = Lexer::new(black_box(&source));
            lexer.tokenize().unwrap()
        })
    });
}

// 性能目标：
// - 10K 行代码 < 5ms
// - 100K 行代码 < 50ms
// - 吞吐量 > 50MB/s
```
