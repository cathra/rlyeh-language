### 增量编译逻辑

```rust
impl ModuleCache {
    /// 检查模块是否需要重编译
    pub fn needs_recompile(&self, module: &Module) -> bool {
        let source_hash = hash_file(&module.source_path);
        
        // 1. 源文件是否变化
        if self.get_source_hash(module.id) != source_hash {
            return true;
        }
        
        // 2. 公共接口是否变化
        let current_interface = compute_interface_hash(module);
        if self.get_interface_hash(module.id) != current_interface {
            return true;
        }
        
        // 3. 依赖的接口是否变化
        for dep in &module.dependencies {
            let cached_dep = self.get_dep_info(dep.module);
            if cached_dep.interface_hash != dep.interface_hash {
                return true;
            }
        }
        
        false
    }
    
    /// 编译单个模块
    pub fn compile_module(&mut self, module: &Module) -> Result<()> {
        if !self.needs_recompile(module) {
            // 直接使用缓存
            return Ok(());
        }
        
        // 编译
        let artifact = compile(module)?;
        
        // 更新缓存
        self.update_entry(module, artifact);
        
        Ok(())
    }
}
```

### 并行编译

```rust
pub struct ParallelCompiler {
    /// 任务队列
    queue: WorkStealingQueue<CompileTask>,
    /// 工作线程
    workers: Vec<CompileWorker>,
    /// 编译结果
    results: HashMap<ModuleId, CompileResult>,
}

impl ParallelCompiler {
    pub fn compile_all(&mut self, modules: &[Module]) {
        // 1. 构建依赖图
        let dep_graph = build_dependency_graph(modules);
        
        // 2. 拓扑排序，分层
        let layers = topological_layers(&dep_graph);
        
        // 3. 同层并行编译
        for layer in layers {
            let handles: Vec<_> = layer.into_iter()
                .map(|module| {
                    let module = module.clone();
                    thread::spawn(move || compile(module))
                })
                .collect();
            
            for h in handles {
                h.join().unwrap();
            }
        }
    }
}
```

### 依赖解析（PubGrub 算法）

```rust
/// 使用 PubGrub 算法解析依赖
/// 这是目前最优的依赖解析算法（Rust 也在用）
pub fn resolve_dependencies(
    root: &Package,
    registry: &Registry,
) -> Result<DependencyGraph> {
    let mut state = PubGrubState::new(root);
    
    loop {
        match state.next_decision() {
            Decision::Pick(pkg, version) => {
                let deps = registry.get_dependencies(&pkg, &version)?;
                state.add_constraints(deps);
            }
            Decision::Backtrack(conflict) => {
                state.backtrack(conflict)?;
            }
            Decision::Done(graph) => {
                return Ok(graph);
            }
        }
    }
}
```

### 沙箱构建

```rust
/// 下载的依赖在隔离环境中编译
pub fn sandbox_build(dep: &Dependency) -> Result<()> {
    // 1. 创建临时目录
    let sandbox = TempDir::new()?;
    
    // 2. 下载源码
    let source = download(&dep.url)?;
    extract(&source, sandbox.path())?;
    
    // 3. 在沙箱中编译
    let output = Command::new("rlyeh")
        .arg("build")
        .arg("--sandbox")
        .arg(format!("--sandbox-root={}", sandbox.path().display()))
        .output()?;
    
    if !output.status.success() {
        return Err(Error::BuildFailed(output.stderr));
    }
    
    // 4. 验证产物
    verify_artifact(&output.path)?;
    
    Ok(())
}
```

fn check_simplifiable(chain: &ComparisonChain) -> Option<LintWarning> {
    // 检测 0 <= x && x < 10 这种应该写成 0 <= x < 10
    if chain.can_be_math_chain() {
        return Some(LintWarning {
            rule: LintRule::SuggestMathSyntax,
            message: "use math chain syntax: 0 <= x < 10".to_string(),
            suggestion: Some("0 <= x < 10".to_string()),
        });
    }
    None

## REPL

```rust
/// 交互式 Rlyeh 解释器
pub struct Repl {
    /// 当前会话的状态
    state: ReplState,
    /// 历史记录
    history: Vec<String>,
    /// 代码补全
    completer: ReplCompleter,
}

impl Repl {
    pub fn run(&mut self) {
        println!("Rlyeh REPL v0.1.0");
        println!("Type :help for help, :quit to exit");
        
        loop {
            print!("rlyeh> ");
            stdout().flush();
            
            let line = read_line();
            
            match line.as_str() {
                ":quit" => break,
                ":help" => print_help(),
                ":load" => load_file(),
                _ => self.eval_and_print(&line),
            }
        }
    }
    
    fn eval_and_print(&mut self, code: &str) {
        match self.state.eval(code) {
            Ok(value) => println!("{}", value),
            Err(err) => {
                eprintln!("error: {}", err);
                // 尝试多行输入
                if err.is_incomplete() {
                    self.read_multiline(code);
                }
            }
        }
    }
}
```

## 验收标准

1. `rlyeh new` 生成的脚手架可直接编译运行
2. 增量编译：修改一个文件后，全量重编译时间 < 3s
3. 并行编译：4 核机器上编译速度提升 ≥ 3x
4. 包管理器依赖解析 < 1s（100 个依赖）
5. 格式化器：所有 Rlyeh 标准库代码格式化后无变化
6. Linter：能检测到所有预设规则
7. REPL：支持多行输入、Tab 补全、历史记录
