## 目标

将 Rlyeh 的 MIR（中级中间表示）编译为高效的机器码。

## 编译流水线

```
源代码
  ↓ 词法分析
Token 流
  ↓ 语法分析
AST
  ↓ 名称解析 + 类型检查 + 借用检查
HIR (High-level IR)
  ↓ 高层优化 + 区域分析
MIR (Mid-level IR)
  ↓ 低级优化 + 代码生成
LIR (Low-level IR)
  ↓ 目标代码生成
机器码 / LLVM IR / WASM
```

## 优化 Passes

### 1. 常量折叠

```rust
fn const_fold(expr: MirExpr) -> MirExpr {
    match expr {
        MirExpr::Binary(lhs, op, rhs) => {
            if let (MirExpr::Literal(a), MirExpr::Literal(b)) = (&*lhs, &*rhs) {
                return MirExpr::Literal(eval_const(op, a, b));
            }
            MirExpr::Binary(lhs, op, rhs)
        }
        // 比较链常量折叠
        MirExpr::ComparisonChain(exprs, ops) => {
            let folded: Vec<_> = exprs.into_iter()
                .map(|e| const_fold(e))
                .collect();
            // 如果全部是字面量，直接计算结果
            if folded.iter().all(|e| matches!(e, MirExpr::Literal(_))) {
                let result = eval_chain(&folded, &ops);
                return MirExpr::Literal(Literal::Bool(result));
            }
            MirExpr::ComparisonChain(folded, ops)
        }
        other => other,
    }
}
```

### 2. 死代码消除

```rust
fn dead_code_elimination(block: &mut MirBlock) {
    let mut live_vars = HashSet::new();
    
    // 反向遍历，标记活跃变量
    for stmt in block.stmts.iter().rev() {
        match stmt {
            MirStmt::Assign(var, expr) => {
                if !live_vars.contains(var) {
                    // 死赋值，移除
                    stmt.remove();
                } else {
                    // 标记表达式中使用的变量为活跃
                    mark_used_vars(expr, &mut live_vars);
                }
            }
            _ => {}
        }
    }
}
```

```rust
fn hoist_loop_invariants(loop_block: &mut MirBlock) {
    let mut invariants = Vec::new();
    
    for stmt in &loop_block.stmts {
        if is_invariant(stmt) {
            invariants.push(stmt.clone());
        }
    }
    
    // 将不变量移到循环外
    prepend_to_parent(&invariants);
    remove_from_loop(&invariants);
```

## 代码生成（LLVM 后端）

### 函数代码生成

```rust
impl CodeGen {
    fn gen_function(&mut self, func: &MirFunction) -> llvm::ValueRef {
        // 创建函数
        let llvm_fn = self.create_function(&func.name, &func.signature);
        
        // 创建基本块
        let entry = self.append_basic_block(llvm_fn, "entry");
        self.builder.position_at_end(entry);
        
        // 为参数创建 alloca
        for (i, param) in func.params.iter().enumerate() {
            let alloca = self.create_alloca(param.type);
            self.builder.build_store(alloca, self.get_param(i));
            self.locals.insert(param.id, alloca);
        }
        
        // 生成函数体
        self.gen_block(&func.body);
        
        // 确保有返回值
        if func.return_type == Type::Unit {
            self.builder.build_ret_void();
        }
        
        llvm_fn
    }
    
    fn gen_stmt(&mut self, stmt: &MirStmt) {
        match stmt {
            MirStmt::Assign(var, expr) => {
                let value = self.gen_expr(expr);
                let ptr = self.locals[var];
                self.builder.build_store(ptr, value);
            }
            MirStmt::If(cond, then_block, else_block) => {
                let cond_val = self.gen_expr(cond);
                let then_bb = self.create_block("then");
                let else_bb = self.create_block("else");
                let merge_bb = self.create_block("merge");
                
                self.builder.build_cond_br(cond_val, then_bb, else_bb);
                
                self.builder.position_at_end(then_bb);
                self.gen_block(then_block);
                self.builder.build_br(merge_bb);
                
                self.builder.position_at_end(else_bb);
                if let Some(else_b) = else_block {
                    self.gen_block(else_b);
                }
                self.builder.build_br(merge_bb);
                
                self.builder.position_at_end(merge_bb);
            }
            // ... 其他语句
        }
    }
}
```

### 比较链代码生成

```rust
fn gen_comparison_chain(
    &mut self,
    exprs: &[MirExpr],
    ops: &[CompOp],
) -> llvm::ValueRef {
    let direction = check_direction(ops);
    
    // 生成所有两两比较
    let mut comparisons = Vec::new();
    for i in 0..ops.len() {
        let lhs = self.gen_expr(&exprs[i]);
        let rhs = self.gen_expr(&exprs[i + 1]);
        let cmp = match ops[i] {
            CompOp::Lt => self.builder.build_icmp(llvm::IntPredicate::SLT, lhs, rhs),
            CompOp::Le => self.builder.build_icmp(llvm::IntPredicate::SLE, lhs, rhs),
            CompOp::Gt => self.builder.build_icmp(llvm::IntPredicate::SGT, lhs, rhs),
            CompOp::Ge => self.builder.build_icmp(llvm::IntPredicate::SGE, lhs, rhs),
            _ => unreachable!(),
        };
        comparisons.push(cmp);
    }
    
    // 用 && 或 || 连接
    match direction {
        Forward => fold_with_and(self.builder, &comparisons),
        Backward => fold_with_or(self.builder, &comparisons),
    }
}
```

### 区域代码生成

```rust
fn gen_region_begin(&mut self, region_id: RegionId, options: &RegionOptions) {
    // 调用 __rlyeh_region_create(size, options)
    let size = self.const_u64(options.initial_size as u64);
    let opts = self.const_u64(options.to_bits());
    self.builder.build_call(
        self.runtime_fn("__rlyeh_region_create"),
        &[size, opts],
    );
}

fn gen_region_alloc(&mut self, var: VarId, region: RegionId, ty: TypeId, size: usize) {
    // 调用 __rlyeh_region_alloc(region, size, align)
    let region_ptr = self.get_region(region);
    let size_val = self.const_u64(size as u64);
    let align_val = self.const_u64(ty.align() as u64);
    let ptr = self.builder.build_call(
        self.runtime_fn("__rlyeh_region_alloc"),
        &[region_ptr, size_val, align_val],
    );
    self.locals.insert(var, ptr);
}

fn gen_region_end(&mut self, region: RegionId) {
    // 调用 __rlyeh_region_destroy(region)
    // 内部会：1. 执行析构 2. 释放内存
    let region_ptr = self.get_region(region);
    self.builder.build_call(
        self.runtime_fn("__rlyeh_region_destroy"),
        &[region_ptr],
    );
}
```

```rust
fn lto(program: &mut MirProgram) {
```

## 验收标准

1. 生成的代码性能不低于 Rust 同级代码
2. 比较链展开后无冗余比较
3. 区域代码生成正确（分配、析构、释放）
4. WASM 输出体积 < 同等 Rust 编译结果
5. LTO 有效减少二进制体积 10%+
6. 编译速度：百万行 < 30s（全量），< 3s（增量）
