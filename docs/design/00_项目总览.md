# Rlyeh 系统级编程语言 — CodeBuddy Prompt 项目

## 项目概述

Rlyeh 是一门面向系统编程的新语言，目标是结合 Rust 的安全性、Go 的编译速度、Erlang 的并发模型和数学式的语法表达。

## 设计原则（所有 Prompt 必须遵守）

1. **零开销抽象**：所有语法糖在编译期展开，不引入运行时成本
2. **数学式表达**：条件判断使用 `0 < i < 10` 和 `i in (1, 3, 5)` 形式
3. **智能区域分配**：编译期静态分析 + PGO + 运行时自适应三层递进
4. **安全第一**：默认安全，unsafe 作为逃生舱显式标注
5. **可读优先**：代码应该像数学公式和自然语言一样易读
6. **测试防挂起（硬性规则）**：运行测试用例必须考虑测试可能挂起的情况，任何测试执行都必须带超时保护；只有命令**正常返回且退出码为 0** 才算通过，无限等待/超时一律视为失败并必须定位修复

## 技术栈建议

- 编译器前端：Rust（自举目标）
- 编译器后端：LLVM IR / Cranelift
- 解析器生成：手写递归下降（无第三方依赖）
- 测试框架：内置 `rlyeh test`
- 文档生成：从 `///` 注释自动提取

## CodeBuddy 协作规则

### 任务分配原则

每个 Prompt 文件（P001-P013）对应一个**独立的可交付模块**。CodeBuddy 应：

1. **严格按编号顺序**执行 Prompt，前一个未完成不要跳到下一个
2. 每个 Prompt 完成后，**必须跑通所有测试用例**再进入下一个
3. 如果某个 Prompt 的依赖未完成，应**主动报告阻塞**而不是猜测

### 代码风格要求

```rust
// ✅ 正确：清晰的命名、文档注释、错误处理
/// Lexer 结构体，负责将源代码转换为 Token 流。
///
/// # Example
/// ```
/// let lexer = Lexer::new("let x = 42;");
/// let tokens = lexer.tokenize();
/// ```
pub struct Lexer<'src> {
    source: &'src str,
    pos: usize,
}

impl<'src> Lexer<'src> {
    /// 创建新的 Lexer 实例。
    pub fn new(source: &'src str) -> Self {
        Self { source, pos: 0 }
    }

    /// 执行词法分析，返回 Token 向量。
    pub fn tokenize(&mut self) -> Result<Vec<Token>, LexError> {
        // ...
    }
}

// ❌ 错误：无文档、无错误处理、命名模糊
pub struct L {
    s: String,
    p: usize,
}
```

### 错误处理规范

- 使用 `thiserror` 定义错误类型
- 错误信息必须包含**位置信息**（行号、列号）
- 错误信息必须**可执行**（告诉用户怎么修）

```rust
#[derive(Debug, thiserror::Error)]
pub enum LexError {
    #[error("invalid character '{ch}' at {line}:{col}")]
    InvalidChar { ch: char, line: usize, col: usize },

    #[error("unterminated string literal starting at {line}:{col}")]
    UnterminatedString { line: usize, col: usize },
}
```

### 测试要求

- 每个公开函数必须有至少一个单元测试
- 每个模块必须有至少一个集成测试
- 性能敏感模块必须有基准测试（criterion）
- 模糊测试覆盖解析器入口
- **【硬性规则】运行测试必须考虑挂起风险**：并发/异步类测试（Actor、调度器、通道、锁、`join` 等）尤其容易挂起，执行时须用超时包裹（如 `timeout` / `gtimeout`，或脚本级 deadline）；通过标准是命令**正常返回且退出码为 0**；挂起或超时即视为测试失败，必须定位根因并修复，不得跳过或无限重试

### 接口约定

各阶段之间通过**明确的类型边界**通信：

```rust
// rlyeh-lexer/src/lib.rs
pub fn tokenize(source: &str) -> Result<Vec<Token>, LexError>;

// rlyeh-parser/src/lib.rs
pub fn parse(tokens: Vec<Token>) -> Result<AstProgram, ParseError>;

// rlyeh-typecheck/src/lib.rs
pub fn typecheck(ast: AstProgram) -> Result<HirProgram, TypeError>;

// rlyeh-borrowck/src/lib.rs
pub fn borrow_check(hir: HirProgram) -> Result<HirProgram, BorrowError>;

// rlyeh-regionck/src/lib.rs
pub fn region_check(hir: HirProgram) -> Result<HirProgram, RegionError>;
```

## 语言规范参考（供编译器实现参考）

> 权威定义见 [`docs/grammar.md`](../grammar.md) 与 [`docs/semantics.md`](../semantics.md)。本节仅为速查。

### 完整关键字列表

```
// 基础
let, mut, const, static, fn, return, pub, priv

// 控制流
if, else, match, for, while, loop, break, continue

// 逻辑
true, false, and, or, not

// 类型
struct, enum, trait, impl, type, where, Self

// 内存管理
region, in, transfer, out, of, unsafe

// 并发
actor, async, await, spawn, send, recv

// 模块
mod, use, as, pub, extern

// 其他
@bind_from_c_header, @specialize, @for
```

### 运算符优先级

```
优先级  运算符                          结合性
1       ::                              左
2       ., (), [], ?, in（后缀 in 区域） 左
3       !, -, *, &, &mut                右（一元）
4       as                              左
5       *, /, %                         左
6       +, -                            左
7       <<, >>                          左
8       <, <=, >, >=, ==, !=            左（比较链）
9       in, not in                       左
10      &                               左（按位与）
11      ^                               左
12      |                               左
13      and, &&                          左
14      or, ||                           左
15      =, +=, -=, *=, /=               右
```

> 比较链语义见下节；`in` 在第 2 级为区域后缀（`x in 'r`），在第 9 级为集合/区间判断（`x in (1, 3, 5)`）。

### 比较链语义

```
# 正向链（区间内）
0 < x < 10        →  x > 0 && x < 10
0 <= x <= 10     →  x >= 0 && x <= 10
a < b < c        →  a < b && b < c

# 反向链（区间外）
0 > x > 10       →  x < 0 || x > 10
0 >= x >= 10     →  x <= 0 || x >= 10

# 混合（编译错误）
0 < x > 10       →  ERROR: inconsistent direction
```

### 区域系统语义

```
region 'r { ... }              → 基本区域
region 'r with_size(N) { ... } → 指定初始大小
region 'r allow_growth { ... } → 允许扩容
region 'r adaptive { ... }     → 运行时自适应
region 'r exact(N) { ... }     → 精确大小，禁止扩容

let x = Expr in 'r;            → 在区域内分配
transfer x out of 'r;          → 转移所有权到外部
```

## 与 CodeBuddy 的交互协议

### Prompt 执行流程

```
用户 → CodeBuddy: "执行 P001"
