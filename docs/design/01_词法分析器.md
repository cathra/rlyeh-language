## 目标

将 Rlyeh 源代码转换为 Token 流，供语法分析器消费。

## 需要支持的 Token 类型

### 关键字
```
let, mut, const, static, fn, return, if, else, match, loop, while, for, in,
region, transfer, actor, async, await, pub, mod, use, trait, impl, struct,
enum, type, where, Self, self, true, false, null, break, continue,
unsafe, extern, crate, super, as, ref, move, dyn, box, not
```

### 比较运算符（重点）
```
<, <=, >, >=, ==, !=,
in, not in, and, or
```

### 逻辑运算符
```
&&, ||, !
```

### 算术运算符
```
+, -, *, /, %, **
```

### 位运算符
```
&, |, ^, <<, >>, ~
```

### 分隔符
```
(, ), {, }, [, ], ,, ;, :, ::, ., ->
```

### 字面量
```
整数: 42, 0xFF, 0b1010, 1_000_000
浮点: 3.14, 2.718e-10
字符: 'a', '\n', '中'
字符串: "hello", "line1\nline2"
原始字符串: r"raw string with \n"
时间: 9am, 6pm, 22:00, 09:30:45
区间: .., ..=
```

### 标识符
```
[a-zA-Z_][a-zA-Z0-9_]*
```

## 特殊 Token 处理

### 时间字面量
`9am`, `6pm`, `22:00` 需要被识别为时间 Token，而非普通标识符或数字。

### 区间符号
`..` 和 `..=` 需要优先匹配，不能拆成两个 `.`。

### 比较链
`<=` 和 `>=` 必须优先于 `<` 和 `>` 匹配。

## 交付物

- `lexer.rs`：词法分析器实现

## 验收标准

1. 能正确 tokenize 所有 Rlyeh 示例代码
2. 时间字面量识别准确率 100%
3. 比较运算符优先级正确
4. 性能：百万行代码 tokenize 时间 < 500ms
