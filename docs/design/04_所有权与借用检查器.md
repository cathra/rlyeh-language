## 目标

在编译期保证内存安全，无需垃圾回收。

## 核心规则

1. 每个值有且只有一个所有者
2. 同一时刻，要么有多个不可变引用，要么有一个可变引用
3. 引用必须始终有效（生命周期 ≤ 被引用值的生命周期）
4. `transfer` 可以将区域对象的所有权转移到外部

## 借用检查器实现

```rust
struct BorrowChecker {
    // 变量 → 所有权信息
    owners: HashMap<VarId, OwnershipInfo>,
    
    // 当前作用域的借用信息
    borrows: Vec<BorrowInfo>,
    
    // 生命周期约束集合
    lifetime_constraints: Vec<(Lifetime, Lifetime)>,
    
    // 区域信息
    regions: HashMap<RegionId, RegionInfo>,
}

struct OwnershipInfo {
    var: VarId,
    status: OwnershipStatus,  // Owned / Moved / Borrowed
    region: Option<RegionId>,  // 所属区域
}

struct BorrowInfo {
    var: VarId,
    borrow_kind: BorrowKind,  // Immutable | Mutable
    scope: ScopeId,
    lifetime: Lifetime,
}
```

## 检查流程

### 1. 移动语义

```rust
fn check_move(&mut self, var: VarId, location: Location) {
    let info = self.owners.get_mut(&var).unwrap();
    
    match info.status {
        OwnershipStatus::Owned => {
            info.status = OwnershipStatus::Moved;
        }
        OwnershipStatus::Moved => {
            self.error(location, "use of moved value");
        }
        OwnershipStatus::Borrowed => {
            self.error(location, "cannot move while borrowed");
        }
    }
}
```

### 2. 借用规则

```rust
fn check_borrow(&mut self, var: VarId, kind: BorrowKind) {
    let info = self.owners.get(&var).unwrap();
    
    match kind {
        BorrowKind::Immutable => {
            // 可以有多个不可变借用
            // 但不能有活跃的可变借用
            if self.has_active_mutable_borrow(var) {
                self.error("cannot borrow immutably while borrowed mutably");
            }
        }
        BorrowKind::Mutable => {
            // 只能有一个可变借用，且不能有不可变借用
            if self.has_any_active_borrow(var) {
                self.error("cannot borrow mutably while already borrowed");
            }
        }
    }
}
```

### 3. 生命周期推断

```rust
fn infer_lifetimes(&mut self, expr: &Expr) -> Lifetime {
    match expr {
        Expr::Ident(var) => {
            self.owners[var].lifetime
        }
        Expr::Ref(expr, kind) => {
            let inner_lt = self.infer_lifetimes(expr);
            // 引用的生命周期不能超过被引用值
            let ref_lt = self.fresh_lifetime();
            self.lifetime_constraints.push((ref_lt, inner_lt));
            ref_lt
        }
        // ...
    }
}
```

## 区域借用检查

```rust
struct RegionInfo {
    id: RegionId,
    name: String,
    parent: Option<RegionId>,  // 嵌套区域
    allocations: Vec<VarId>,   // 区域内分配的对象
    destructors: Vec<DestructorEntry>,
    options: RegionOptions,
}

// 区域内引用的规则
fn check_region_borrow(&self, borrow: &BorrowInfo, region: &RegionId) {
    let borrowed_var = borrow.var;
    let var_region = self.owners[&borrowed_var].region;
    
    // 引用只能指向同一区域或外层区域的对象
    if !self.is_same_or_outer_region(var_region, *region) {
        self.error("cannot borrow from inner or unrelated region");
    }
}

// transfer 检查
fn check_transfer(&self, var: VarId, target_scope: ScopeId) -> Result<()> {
    let info = &self.owners[&var];
    
    // 1. 变量必须在某个区域内
    let region = info.region.ok_or("variable is not in a region")?;
    
    // 2. 目标作用域必须在区域外部
    if self.is_inside_region(target_scope, region) {
        return Err("cannot transfer to inner scope");
    }
    
    // 3. 变量不能有活跃借用
    if self.has_any_active_borrow(var) {
        return Err("cannot transfer while borrowed");
    }
    
    // 4. 从区域的析构列表中移除
    self.regions[&region].destructors.retain(|d| d.var != var);
    
    Ok(())
}
```

## 验收标准

1. 所有 Rust 能捕获的内存安全问题都能捕获
2. 合法代码不会被误报
3. 错误信息清晰，附带修复建议
4. 支持区域系统和 transfer 语义
5. 性能：百万行代码检查时间 < 5s
