## 目标

实现 Zeta 的分层内存管理体系，核心是智能区域分配器。

## 分层架构

```
L0 - 静态所有权（Rust 风格，编译期确定）
L1 - 区域系统（智能分配，批量释放）
L2 - 引用计数（Rc/Arc，标准库提供）
L3 - 追踪式 GC（可选插件）
```

本文件聚焦于 L1 区域系统。

## 区域分配器设计

### 核心数据结构

```rust
/// 一个区域由多个内存块组成（链表式扩展）
pub struct Region {
    /// 区域唯一标识
    id: RegionId,
    /// 区域名称（用于错误报告和 profiling）
    name: String,
    /// 内存块链表
    blocks: Vec<MemoryBlock>,
    /// 当前活跃块索引
    current_block: usize,
    /// 析构函数列表（按注册顺序）
    destructors: Vec<DestructorEntry>,
    /// 已分配总字节数（用于统计）
    total_allocated: usize,
    /// 分配次数（用于统计）
    allocation_count: usize,
    /// 扩容历史（用于自适应策略）
    growth_history: Vec<GrowthRecord>,
    /// 分配策略
    strategy: AllocStrategy,
    /// 配置选项
    options: RegionOptions,
    /// 统计信息（用于 PGO）
    stats: RegionStats,
}

pub struct MemoryBlock {
    /// 块起始地址
    start: *mut u8,
    /// 当前分配指针（bump pointer）
    current: *mut u8,
    /// 块结束地址
    end: *mut u8,
    /// 块大小
    size: usize,
    /// 是否被迁出（transfer）过
    has_transfers: bool,
}

pub struct DestructorEntry {
    /// 对象指针
    ptr: *mut u8,
    /// 析构函数
    drop_fn: unsafe fn(*mut u8),
    /// 对象大小（用于调试）
    size: usize,
}

pub struct GrowthRecord {
    /// 扩容前大小
    before: usize,
    /// 扩容后大小
    after: usize,
    /// 扩容时的时间戳
    timestamp: Instant,
}
```

### 分配策略

```rust
pub enum AllocStrategy {
    /// 静态分析决定大小，失败则报错
    Static,
    /// 使用 PGO 数据
    Pgo(PathBuf),
    /// 运行时自适应
    Adaptive {
        initial_size: usize,

    },
    /// 完全自动（默认：先静态 → 失败则用自适应）
    Auto,
}

pub struct RegionOptions {
    /// 初始大小（字节）
    pub initial_size: usize,
    /// 是否允许扩容
    pub allow_growth: bool,
    /// 扩容因子
    pub growth_factor: f64,
    /// 最大大小限制（0 = 无限制）
    pub max_size: usize,
    /// 精确模式（不允许扩容，超出则 panic）
    pub exact: bool,
}
```

## 核心算法

### 1. Bump Allocate（区域内分配）

```rust
impl Region {
    /// 在区域内分配内存
    pub fn allocate(&mut self, size: usize, align: usize) -> *mut u8 {
        // 对齐当前指针
        let aligned = align_up(self.current_ptr(), align);
        let new_ptr = aligned + size;
        
        // 检查当前块是否有足够空间
        if new_ptr <= self.current_block().end {
            // 快速路径：直接 bump
            self.set_current_ptr(new_ptr);
            self.total_allocated += size;
            self.allocation_count += 1;
            return aligned;
        }
        
        // 慢速路径：需要新块
        self.grow(size, align)
    }
    
    fn grow(&mut self, min_size: usize, align: usize) -> *mut u8 {
        if !self.options.allow_growth {
            if self.options.exact {
                panic!("Region '{}' exact size exceeded: need {} bytes", 
                       self.name, min_size);
            } else {
                panic!("Region '{}' growth disabled but size exceeded", 
                       self.name);
            }
        }
        
        // 计算新块大小
        let new_size = self.calculate_next_size(min_size);
        
        // 检查最大限制
        if self.options.max_size > 0 {
            let total = self.total_blocks_size() + new_size;
            if total > self.options.max_size {
                panic!("Region '{}' max size {} exceeded", 
                       self.name, self.options.max_size);
            }
        }
        
        // 记录扩容
        let old_size = self.current_block().size;
        self.growth_history.push(GrowthRecord {
            before: old_size,
            after: new_size,
            timestamp: Instant::now(),
        });
        
        // 分配新块
        let new_block = MemoryBlock::new(new_size);
        self.blocks.push(new_block);
        self.current_block = self.blocks.len() - 1;
        
        // 在新块上分配
        self.allocate(min_size, align)
    }
}
```

### 2. 智能大小计算（三层递进）

```rust
impl Region {
    fn calculate_next_size(&self, min_required: usize) -> usize {
        match self.strategy {
            AllocStrategy::Static => {
                // 静态模式不应该走到这里
                panic!("Static region exhausted");
            }
            
            AllocStrategy::Adaptive { growth_factor, .. } => {
                // 自适应：基于历史增长率
                if self.growth_history.is_empty() {
                    // 首次扩容：用最小需求 × 2
                    max(min_required * 2, 4096)
                } else {
                    let rate = self.estimate_growth_rate();
                    let predicted = (self.current_block().size as f64 * rate) as usize;
                    max(predicted, min_required * 2)
                }
            }
            
            AllocStrategy::Pgo(ref profile_path) => {
                // 使用 PGO 数据
                let profile = PgoProfile::load(profile_path);
                let region_id = self.name.as_str();
                if let Some(data) = profile.get_region_data(region_id) {
                    // 使用 P95 作为初始大小
                    data.p95_size
                } else {
                    // 没有数据，回退到自适应
                    self.calculate_next_size(min_required)
                }
            }
            
            AllocStrategy::Auto => {
                // 默认：使用自适应
                self.calculate_next_size(min_required)
            }
        }
    }
    
    fn estimate_growth_rate(&self) -> f64 {
        if self.growth_history.len() < 2 {
            return 2.0; // 默认翻倍
        }
        
        // 计算历史增长率的加权平均
        let mut weighted_sum = 0.0;
        let mut weight_sum = 0.0;
        
        for (i, record) in self.growth_history.iter().enumerate() {
            let rate = record.after as f64 / record.before as f64;
            // 越近的记录权重越大
            let weight = (i + 1) as f64;
            weighted_sum += rate * weight;
            weight_sum += weight;
        }
        
        let avg_rate = weighted_sum / weight_sum;
        
        // 限制增长率范围 [1.5, 4.0]
        avg_rate.max(1.5).min(4.0)
    }
}
```

### 3. 析构管理

```rust
impl Region {
    /// 注册析构函数
    pub fn register_destructor(
        &mut self, 
        ptr: *mut u8, 
        drop_fn: unsafe fn(*mut u8),
        size: usize,
    ) {
        self.destructors.push(DestructorEntry {
            ptr,
            drop_fn,
            size,
        });
    }
    
    /// 注销析构函数（transfer 时调用）
    pub fn unregister_destructor(&mut self, ptr: *mut u8) {
        self.destructors.retain(|d| d.ptr != ptr);
    }
    
    /// 区域结束：执行析构 + 释放内存
    pub fn destroy(&mut self) {
        // 第一步：逆序执行所有析构函数
        // （逆序保证依赖关系：后创建的对象先销毁）
        for entry in self.destructors.iter().rev() {
            unsafe { (entry.drop_fn)(entry.ptr) };
        }
        
        // 第二步：释放所有内存块
        for block in &self.blocks {
            block.deallocate();
        }
        
        // 第三步：重置统计
        self.destructors.clear();
        self.blocks.clear();
        self.total_allocated = 0;
        self.allocation_count = 0;
    }
}
```

### 4. Transfer 语义

```rust
impl Region {
    /// 将对象所有权从区域转移出去
    /// 返回对象的指针，由调用者接管生命周期
    pub fn transfer_out<T>(&mut self, ptr: *mut T) -> *mut T {
        let raw_ptr = ptr as *mut u8;
        
        // 1. 验证指针确实在这个区域内
        assert!(self.contains_ptr(raw_ptr), 
                "transfer: pointer not in region");
        
        // 2. 从析构列表中移除
        self.unregister_destructor(raw_ptr);
        
        // 3. 标记该块有迁出（不再整体释放这个对象）
        self.current_block_mut().has_transfers = true;
        
        // 4. 记录统计
        self.stats.transfer_count += 1;
        
        ptr
    }
    
    fn contains_ptr(&self, ptr: *mut u8) -> bool {
        self.blocks.iter().any(|b| {
            let start = b.start as usize;
            let end = b.end as usize;
            let p = ptr as usize;
            p >= start && p < end
        })
    }
}
```

### 大小估算 Pass

```rust
/// 在编译期遍历区域 AST，估算所需内存
fn estimate_region_size(region_ast: &RegionBlock) -> EstimateResult {
    let mut total = 0usize;
    let mut has_dynamic = false;
    
    for stmt in &region_ast.statements {
        match stmt {
            Stmt::Let { init, .. } => {
                let size = estimate_expr_size(init);
                total += size;
            }
            Stmt::For { body, .. } => {
                // 如果循环次数已知（字面量）
                if let Some(count) = infer_loop_count(body) {
                    let body_size = estimate_block_size(body);
                    total += count * body_size;
                } else {
                    has_dynamic = true;
                }
            }
            _ => {}
        }
    }
    
    EstimateResult {
        exact_size: if has_dynamic { None } else { Some(total) },
        min_size: total,
        has_dynamic,
    }
}

/// 生成区域初始化代码
fn codegen_region_init(region: &RegionBlock) -> Vec<Instruction> {
    let estimate = estimate_region_size(region);
    
    match estimate.exact_size {
        Some(size) => {
            // 精确大小：直接设置
            vec![
                AllocRegion {
                    id: region.id,
                    size,
                    strategy: Static,
                }
            ]
        }
        None => {
            // 动态大小：使用 PGO 或自适应
            vec![
                AllocRegion {
                    id: region.id,
                    size: estimate.min_size.max(4096),
                    strategy: if has_pgo_data(region) {
                        Pgo(pgo_path(region))
                    } else {
                        Adaptive {
                            initial_size: estimate.min_size.max(4096),
                            growth_factor: 2.0,
                        }
                    },
                }
            ]
        }
    }
}
```

## PGO 数据收集

```rust
/// 编译器插入的 profiling 桩点
#[repr(C)]
pub struct RegionProfileData {
    pub region_id: &'static str,
    pub call_count: AtomicU64,
    pub total_size: AtomicU64,
    pub max_size: AtomicU64,
    pub growth_events: AtomicU64,
}

/// 区域分配时更新统计
pub fn profile_allocation(profile: &RegionProfileData, size: usize) {
    profile.call_count.fetch_add(1, Ordering::Relaxed);
    profile.total_size.fetch_add(size as u64, Ordering::Relaxed);
}

/// 运行结束后保存 profile 数据
pub fn save_profile_data(path: &Path) -> Result<()> {
    let mut data = PgoProfile::new();
    
    for profile in get_all_profiles() {
        let count = profile.call_count.load(Ordering::Relaxed);
        let total = profile.total_size.load(Ordering::Relaxed);
        let max = profile.max_size.load(Ordering::Relaxed);
        
        data.add_region(RegionPgoData {
            id: profile.region_id.to_string(),
            call_count: count,
            avg_size: if count > 0 { total / count } else { 0 },
            max_size: max,
            p50_size: 0,  // 需要更多采样
            p95_size: max,
            p99_size: max,
        });
    }
    
    data.save(path)?;
    Ok(())
}
```

4. 析构函数按逆序执行
5. 性能：10000 次分配 < 100μs
6. PGO 数据收集对运行时影响 < 5%
