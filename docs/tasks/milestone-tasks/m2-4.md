## 目标

为 Rlyeh 提供 LSP（IDE 支持）MVP：JSON-RPC 2.0 over stdio、文档同步、诊断推送、生命周期管理。

## 执行情况 / 技术细节

- 新 crate `crates/rlyeh-lsp`（`jsonrpc.rs` / `protocol.rs` / `server.rs` / `main.rs`）+ `rlyeh lsp` CLI。
- JSON-RPC 2.0 over stdio（Content-Length 帧，自研 `jsonrpc.rs`，无外部 LSP 依赖）。
- full 文本同步（didOpen/didChange/didClose）+ 诊断推送（复用 `rlyeh-check`，映射为 LSP Diagnostic）。
- initialize 声明 capabilities + shutdown/exit 生命周期；`server.rs::handle` 为纯函数入口。

## 验证

- `server.rs` 11 个单测 + `lsp_e2e_test.rs` 2 个进程级测试（真实二进制 + stdio 帧协议）全通过。
- 详见 [`../leaf/f1-lsp.md`](../leaf/f1-lsp.md) 与阶段 F 索引 [`../../stages/F.md`](../../stages/F.md)。

## 已知限制

- 当前为 MVP：仅 full 文档同步（无增量同步）、基础诊断；补全/跳转/重命名等 IDE 高级能力未实现，非 M2 阻塞项。
