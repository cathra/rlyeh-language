## 目标

泄漏堆对象返回裸指针。

## 背景

阶段 阶段 T 子任务，详见 阶段详情文档 [`stages/T.md`](../../stages/T.md)。

## 技术细节

`Box::leak(b)` → `*mut T` 裸指针（G3 语义，`*p` 读写可用），读取 Box 槽 0 指针值不释放。MVP 退化：目标签名 `fn leak(self) -> &'static mut T`——`&*b` 堆地址取引用需 MIR `AddrOf` 支持任意目标（当前仅变量取址），退化为裸指针值语义等价，`'static` 宽松丢弃（G4）。

## 验证
