# Comptime M2 泛型值/类型参数

> **级别**：P1 · **风险**：🟠 中 · **状态**：🟡 待办 · **归属**：0.3.0（自举执行阶段）
> **索引**：[`../rfc/comptime.md`](../rfc/comptime.md) §5 M2 · **计划**：[`../../development-plan-0.2.0.md`](../../development-plan-0.2.0.md) §3.26

## 目标
`comptime n: i64` / `comptime T: type`：数组长度由 comptime 值确定（消除强制堆分配）；类型级分发接入既有单态化。

## 现状
泛型仅类型参数单态化，值参数（数组长度/缓冲尺寸）尚不能作为泛型参数。

## 验证
corpus-comptime-2：`buf(8)`/`buf(16)` 产出不同长度数组；类型分发对拍。
