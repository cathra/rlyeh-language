# Comptime M0 解释器基础设施

> **级别**：P1 · **风险**：🔴 高 · **状态**：🟡 待办 · **归属**：0.2.0-Z
> **索引**：[`../rfc/comptime.md`](../rfc/comptime.md) §5 M0 · **计划**：[`../../development-plan-0.2.0.md`](../../development-plan-0.2.0.md) §3.26

## 目标
新增 `rlyeh-comptime` crate：建立 comptime 值模型（标量/聚合/类型）与 HIR 树遍历求值器，支持字面量、算术/逻辑/比较、变量绑定、分支（`if`）、循环（`for`/`while`）、函数调用（限 comptime fn 与内建）、元组/结构体/枚举构造、数组下标、字段访问。复用 `rlyeh-typecheck` 的 `const` 折叠逻辑作为起点。

## 现状
`const` 折叠（0.2.0-V）仅做常量表达式折叠，无通用 HIR 解释器。

## 验证
单测：解释器对算术/控制流/聚合求值正确；与 `const` 折叠结果对拍。
