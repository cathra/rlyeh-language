# TCL2-4 使用置信证据

> **级别**：P2 · **风险**：🟠 中 · **状态**：🟡 待办 · **归属**：0.2.0-AB（部分延续 0.3.0）
> **索引**：[`../rfc/tcl2-certification.md`](../rfc/tcl2-certification.md) §5.4 · **计划**：[`../../development-plan-0.2.0.md`](../../development-plan-0.2.0.md) §3.28

## 目标
- 现场经验日志：记录真实项目使用、已知缺陷与修复（含 0.2.0 自举前能力落地史）。
- 缺陷追踪与变更管理：工具缺陷登记、影响评估、回归闭环。
- 版本/配置管理：编译器版本、标准库版本、目标平台三元组的资质绑定。

## 现状
无专门资质流程（缺陷追踪/配置管理）。

## 验证
缺陷追踪齐备、至少一轮现场经验/使用历史归档。
