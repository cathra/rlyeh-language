# 2. 词法与字面量

> 本章是**词法（lexer）层面的速查**：标识符规则、所有字面量写法、关键字、注释、运算符字符。配合 [指南 §3 基础语法](../guide/03-basic-syntax.md) 的讲解食用更佳。

---

## 2.1 标识符

```
IDENT = [A-Za-z_][A-Za-z0-9_]*
```

- 以字母或下划线开头，后接字母/数字/下划线。
- 区分大小写：`count` 与 `Count` 是不同标识符。
- 支持 Unicode 字母（可用于变量名，但建议保持 ASCII 以兼容工具链）。

> **C 对照**：和 C 的标识符规则基本一致。Rlyeh 额外允许更多 Unicode 字母（如中文变量名），但工程实践不推荐。

---

## 2.2 字面量（含示例与 C 对照）

| 类别 | 语法 | 示例 | C 对照 / 注意 |
|------|------|------|----------------|
| 整数 | `[0-9]+`（默认 i64） | `42` | `int64_t` 字面量 |
| 十六进制 | `0x` 前缀 | `0xFF`（=255） | 同 C `0xFF` |
| 八进制 | `0o` 前缀 | `0o17`（=15） | C 是 `017`（无 `o`），注意区别 |
| 二进制 | `0b` 前缀 | `0b1010`（=10） | 同 C `0b1010`（C23）/ GCC 扩展 |
| 浮点 | `[0-9]+\.[0-9]+`（f64） | `3.14`, `1e10`, `2.5E-3` | `double` 字面量；Rlyeh 浮点默认 f64 |
| 布尔 | `true` / `false` | — | `_Bool` |
| 字符 | 单引号（**32 位 Unicode 码点**） | `'a'`, `'€'`, `'\n'` | **注意**：C 的 `char` 是 8 位，Rlyeh `char` 是 32 位码点！`'\n'` 在 Rlyeh 是码点 10 |
| 字符串 | 双引号（UTF-8 字节序列） | `"hello"` | C 是 `\0` 结尾 `char*`；Rlyeh 是 `String` 字面量（值语义，自动升级） |
| 原始字符串 | `r#"..."#`（任意 `#` 定界，无转义） | `r#"a"b"c"#` | 等价于 Rust 的 `r#"..."#`；内部可含 `"` 和 `\` 不被转义 |
| 时间 | 分钟单位（`9am`=540 / `6pm`=1080） | `9am`, `6pm` | 无 C 对应；用于比较链/区间判断（见 [指南 §4.6](../guide/04-math-conditions.md)） |
| 区间 | 半开 `..<` / 双闭 `...` | `0..<10`, `0...10` | 无 C 对应；用于 `for` 与 `in` 区间判断 |
| 数组 | `[...]` | `[1, 2, 3]` | C 数组字面量（但 Rlyeh 是值语义拷贝） |
| 单元 | `()` | — | 类似 C 的 `void` 返回 |

### 字符字面量细节（易错）

Rlyeh 的 `char` 是 **32 位 Unicode 码点**（codegen 为 i32），与 C 的 8 位 `char` 不同：

```rlyeh
let a = 'a';           // char，码点 97
let n = '\n';          // char，码点 10（换行）
let euro = '€';        // char，码点 8364（多字节字符也能放一个 char 里）
println(a as i64);     // 97：char → 整数即码点值
```

> **C 对照**：`'\n'` 在 C 里是 `char`（值 10，1 字节）；在 Rlyeh 里是 `char`（值 10，4 字节）。数值相同，但存储宽度不同——跨 FFI 传字符时要用 `u8`/`i32` 对齐（见 [指南 §12.5](../guide/12-ffi.md)）。

### 原始字符串

```rlyeh
let path = r#"C:\Users\name\file.txt"#;   // 反斜杠不被转义，原样保留
let nested = r##"他说："hi""##;            // 用更多 # 可包含 " 或 # 本身
```

> 与 `r#ident`（原始标识符）区分：`r#"..."#` 是原始**字符串**，`r# ident` 是原始**标识符**（用于关键字当名字）。

## 2.3 关键字与保留字

```
fn let mut pub const struct enum protocol impl module import if else while loop for
in break continue match return async await send actor region transfer self
true false type extern as ref
```

- `Str` 类型保留（未实现，勿用）。
- `move` 关键字 MVP **忽略**（所有权宽松）：写了也不报错，但目前不激活"移动语义"的特殊行为。
- 生命周期标注 `'a` 是语法接受但宽松检查的（见 §3.5）。

---

## 2.4 注释

```rlyeh
// 行注释（单行）
/// 文档注释（rlyeh doc 提取生成 Markdown，写在项上方）
// 块注释当前未列出，以行注释为主
```

> **C 对照**：`//` 同 C99 的 `//`；`///` 类似 Doxygen/Javadoc 的 `/**`，用于自动生成文档。`/* ... */` 块注释如需要请以实际编译器支持为准。

## 2.5 运算符字符

```
+ - * / % = == != < <= > >= && || ! not & | ^ << >> ~ ? as @ => . .. ... ..< : ; , ( ) { } [ ]
```

- **注意 `not`**：`not` 是一元逻辑非运算符（等价于 `!`），例如 `not x` 等同 `!x`。
- **注意 `..<` / `...`**：范围运算符（半开 / 双闭），不是比较。
- **注意 `|` 的双重身份**：在类型里 `A | B` 是**类型联合**；在闭包里 `|x| body` 是**闭包参数分隔**；在 `match` 臂之间 `=> ...` 后面不出现。优先级见 [§4](./04-expressions-operators.md)。

## 更多示例

各种字面量写法与对应值：

```rlyeh
let i = 0xFF;           // 255（十六进制）
let o = 0o17;           // 15（八进制，注意不是 C 的 017）
let b = 0b1010;         // 10（二进制）
let c = '€';            // char 码点 8364（32 位，可放任意 Unicode）
let raw = r#"C:\a\b"#;  // 原始字符串，反斜杠不转义
```

可运行版本见 [`examples/by-chapter/03-basic-syntax.rl`](../../examples/by-chapter/03-basic-syntax.rl)（含整数字面量使用）。
