# 3. 类型系统

## 3.1 值类型（标量）

| 类型 | 说明 | 字节 | 备注 |
|------|------|------|------|
| `i8` | 有符号 8 位整数 | 1 | |
| `i16` | 有符号 16 位整数 | 2 | |
| `i32` | 有符号 32 位整数 | 4 | |
| `i64`（默认） | 有符号 64 位整数 | 8 | `let x = 6;` 推断为 i64 |
| `isize` | 指针宽有符号整数 | — | 与 `i64` 不相交 |
| `u8` | 无符号 8 位整数 | 1 | |
| `u16` / `u32` / `u64` / `usize` | 无符号整数 | — | |
| `f32` / `f64`（默认浮点） | 浮点 | 4 / 8 | `let y = 3.14;` 推断为 f64 |
| `bool` | 布尔 | 1 | `true` / `false` |
| `char` | Unicode 码点（32 位） | 4 | 升级为 32 位，`'a' as i64` = 97 |
| `()` | 单元类型 | 0 | 空返回 |

## 3.2 聚合类型

| 类型 | 说明 |
|------|------|
| `struct { ... }` | 具名字段聚合；`Point { x: 1, y: 2 }` 字面量构造 |
| `[T; N]` | 定长数组（N 编译期已知）；`[1, 2, 3]` / `[i64; 4]` |
| `Vec<T>` | 动态数组（标准库）；`Vec::new()` / `vec![...]` |
| `String` | UTF-8 字符串缓冲（标准库） |
| `Str` | **未实现**，勿用 |
| `&T` / `&mut T` | 引用（G1 ✅）；`&x` / `&mut x` 表达式；`*` 解引用；字段/方法自动剥引用层 |
| `&str` | String 只读借用视图（`s.as_str()`，零拷贝） |
| `&[T]` / `&mut [T]` | 切片引用：零拷贝胖指针视图（`{ data, len }`）；`.len()`/`.first()`/`.last()`/`.iter()`；`&[T; N]` 经 unsize coercion → `&[T]`（S1/S2/S3 ✅） |
| `*const T` / `*mut T` | 裸指针（与 `&T` 互视，G3 ✅） |
| `Box<T>` / `Rc<T>` / `Arc<T>` / `Gc<T>` | 智能指针（见 §9） |
| `Option<T>` / `Result<T, E>` | 标准库代数数据类型 |
| `dyn Trait` | trait 对象（2 槽胖指针，H4 ✅） |
| `fn(T) -> R` | 函数指针类型（H1 ✅） |
| `A | B` | 类型联合（见 §3.8，U1/U2 ✅） |
| `enum { ... }` | 具名变体枚举；可带显式判别式（见 §3.9，U3 ✅） |

## 3.3 类型推断

`let` 绑定默认推断：`6` → `i64`，`3.14` → `f64`。函数参数 / 返回须显式注解。闭包参数：有注解用注解，无注解由首次调用点实参推断（延迟固化）。

## 3.4 类型转换

- 隐式：字面量 / 窄化整数（N1 实现：字面量按目标类型 reinterpret 64 位槽，跨整族 / 浮点数值不变）、ASCII 码点转义、字符串字面量升级 String
- `as` 显式（U6 ✅）：数值族 ↔ 之间——向零截断 / 环绕截断；同类型零指令

## 3.5 引用与借用

- `&x` / `&mut x` 表达式、`&T` / `&mut T` 参数与返回、`*` 解引用（G1 ✅）
- `&str` 只读视图（G2 ✅）；`str` 值一等类型（字面量 / 绑定字面量变量自动升级为 String）
- 生命周期标注 `'a`（G4 ✅，语法接受宽松检查，严格验证规划中）
- 严格借用检查（Rust E0502/E0499/E0596/E0597）：`&mut` 排他、局部引用逃逸报 `DanglingReference`

## 3.6 智能指针

| 类型 | 机制 | 实现 |
|------|------|------|
| `Box<T>` | 独占堆分配 | K2 ✅ |
| `Rc<T>` | 引用计数（单线程） | K3 ✅ |
| `Arc<T>` | 原子引用计数（多线程） | K3 ✅ |
| `Gc<T>` | 可选 GC（保守标记-清除） | K4 ✅ |

详见 [manual/std/smart-pointers.md](./std/smart-pointers.md)。

## 3.7 字符串类型

- `String`：堆缓冲（data/len/cap 3 槽），O(n) 扩容
- `str`（字面量值）：运行时为指向静态数据的 `i8*`，参与操作自动升级为 String
- `&str`：只读借用视图，支持 `len()` / `r[i]` / `substring`

## 3.8 类型联合 `A | B`（U1 / U2 ✅）

`A | B` 表示「值为 A 或 B」，运行时为匿名 enum（tag + payload）。成员须两两互不相交（`i64 | isize` 报 `UnionMembersNotDisjoint`）；`match` 用类型臂解构（`i64 => ...`）；未收窄的联合禁止直接运算。

## 3.9 枚举显式判别式（U3 ✅）

`enum Code { Ok = 200, NotFound = 404, Error = 500 }`：判别值即变体 tag，构造与 `match` 均复用。
