# 6. 函数与闭包

## 6.1 函数定义

```rlyeh
fn add(a: i64, b: i64) -> i64 {
    a + b                        // 末表达式返回（隐式 return）
}
```

参数 / 返回须显式类型注解；末表达式为返回值。函数可作值绑定、传递、返回（H1 函数指针）。

## 6.2 闭包

| 形态 | 特性 | 状态 |
|------|------|------|
| `\|x, y\| expr` | 无捕获闭包，desugar 为匿名函数 + fn 指针（零开销） | H2 ✅ |
| `(\|x\| body)(args)` | 捕获闭包（IIFE），按值捕获，立即调用 | H3 ✅ |
| `let f = \|x: i64\| ..; f(..)` | 闭包值对象，反复调用，按值捕获 | H5 ✅ |
| 返回闭包的函数 | `fn make() -> fn(..) { \|x\| .. }` | H5 补全 ✅ |
| 闭包值作 fn 实参 | 无捕获闭包值 → fn 形参降级 / 固化为 fn 指针 | H5 补全 ✅ |

MVP 约束：`move` 忽略、按引用捕获规划中；捕获闭包值不跨函数边界（作 fn 实参 / 返回值报 Unsupported）；参数类型有注解用注解、无注解由首次调用点实参推断（延迟固化，半注解亦可用）。

## 6.3 函数指针

`fn(T) -> R` 类型 + `let f = add` 函数值绑定 + `f(args)` 间接调用（CallIndirect → LLVM `i8*` 槽 + 按签名 bitcast + 间接 call）。函数值可作实参、返回值、重新绑定、类型注解。

## 6.4 trait 对象（H4）

`let d: dyn Trait = &obj;` 经 vtable 胖指针间接分派；去虚拟化（2026-08-24 ✅）：`let d: dyn Trait = &obj;` 绑定变量时记录来源具体类型，后续 `d.method()` 静态分派（dyn 变量被重新赋值时保守回退 vtable 间接调用）。MVP 限制：非泛型 trait/impl、含 `Self` 签名方法不可经 dyn 调用。
