# 3. 第一个程序

```rlyeh
// hello-world.rl
fn main() {
    println("Hello, Rlyeh!");
}
```

编译与运行：

```bash
rlyeh build hello-world.rl     # 生成可执行文件 hello-world
./hello-world
rlyeh run hello-world.rl       # 编译并运行（一步到位）
```
