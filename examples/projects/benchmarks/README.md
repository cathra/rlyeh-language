# Zeta 性能对比基准（benchmarks）

Zeta 语言与 **C / C++ / Swift / Rust** 的全方位性能对比用例集。每个基准在所有语言中实现**逻辑严格一致**（跨语言输出已逐项核对），统一编译、统一计时，公平对比。

> Go 本机未安装，暂缺；本套件结构已为 Go 预留（安装后补 `go` 源文件与编译分支即可）。

## 基准维度（6 项）

| 基准 | 内容 | 考察点 |
|------|------|--------|
| `fib` | fib(30) 双递归 | 函数调用开销 + 整数运算 |
| `loop_sum` | 1 亿次 i64 循环累加 | 整数运算 + 分支 |
| `matmul` | 256×256 f64 矩阵乘法 | 浮点运算 + 内存访问 |
| `strcat` | 字符串拼接 10 万次 | 字符串缓冲扩容 |
| `hashmap` | 20 万 insert + 20 万 get（LCG i64 键） | 哈希表 |
| `sort` | LCG 生成 5000 个 i64 排序 | 排序算法 + 标准库 |

## 运行方式

```bash
python3 run.py                     # 完整跑 6 基准 × 5 语言
python3 run.py --runs 10           # 增加正式运行次数（更稳）
python3 run.py --only fib,matmul   # 只跑指定基准
python3 run.py --skip-zeta-build   # 跳过 Zeta 重编译（复用已有二进制）
```

计时策略：每基准每语言 **warmup 1 次 + 正式 5 次取中位数**（毫秒），进程启动开销各语言一致。

## 编译优化级别（如实声明）

| 语言 | 编译器/优化 | 说明 |
|------|------------|------|
| Zeta | `zeta build` | **当前无优化管线**（最小 MIR 优化 + clang O0 汇编）——反映真实水平 |
| C / C++ | `clang -O3` / `clang++ -O3` | 发布级优化 |
| Swift | `swiftc -O` | 发布级优化 |
| Rust | `rustc -O` | 发布级优化 |

## 最新结果摘要（Apple M5 Pro，2026-08-24）

| 基准 | Zeta | C | C++ | Swift | Rust | Zeta/最优 |
|------|-----:|---:|---:|------:|-----:|:---:|
| fib (ms) | 5.99 | 3.61 | 3.56 | 4.72 | 3.95 | 1.7x |
| loop_sum (ms) | 83.82 | 2.15 | 2.08 | 24.86 | 2.58 | 40.4x |
| matmul (ms) | 70.00 | 12.26 | 12.14 | 13.68 | 11.93 | 5.9x |
| strcat (ms) | 4.95 | 2.14 | 2.28 | 4.11 | 2.33 | 2.3x |
| hashmap (ms) | 26.84 | 4.59 | 8.26 | 8.46 | 5.62 | 5.8x |
| sort (ms) | 42.54 | 2.44 | 2.58 | 3.07 | 2.64 | 17.4x |

### 关键洞察

1. **函数调用密集场景差距最小**：`fib` 仅慢 1.3–1.7x —— 说明 Zeta 的函数调用 ABI 与运行时质量良好，即使在无优化下。
2. **字符串拼接表现优秀**：`strcat` 仅慢 1.2–2.3x（与 Swift 基本持平）—— `String` 缓冲扩容设计合理。
3. **瓶颈在缺优化管线**：`loop_sum`（慢 40x）、`matmul`（慢 6x）的差距主要来自 clang O0 下无循环优化/向量化，属编译优化缺失而非语言设计问题。
4. **`sort` 差距属标准库算法差距**：Zeta `Vec::sort_by` 当前为 O(n²) 选择排序（std-lib §3.1），其余语言为 O(n log n) —— 换用 O(n log n) 实现后差距将收窄到常数级。
5. **绝对性能仍可用**：所有基准 Zeta 都在几十毫秒级完成，作为 MVP 已具实用基础；未来接入优化管线（MIR 优化 + clang -O2 汇编）后仍有数倍提升空间。

## 复现与验证

- 逻辑等价性：所有语言输出逐项一致（`832040` / `4999999950000000` / `200000` / `19999900000` / sort 首尾值相同）。
- LCG 随机数使用统一常数（MMIX：A=6364136223846793005, C=1442695040888963407），Zeta 的 i64 乘法为 wrapping 语义（已实测），C/C++ 用无符号算术保证无 UB。
